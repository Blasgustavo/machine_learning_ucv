## Tpos de algoritmos

- Aprendizaje Supervisado,
- Aprendizae No Superviado
- Por Recompensas refuerzo

### Aprendizaje Supervisado

- Datos de entrada etiquetados
- Objetivo predecir resultados
- Algoritmos Regresion lineal, Arboles de decision,

### Aprendizae No Superviado

- Datos de entrada No etiquetados, solo tienen las caracteristicas
- Objetivo Encontrar patrones o Grupos (Clasificacion)
- Algoritmos K-means
